# Lexico moderno — Latino Simplo para el mundo de hoy

Ampliación del [`lexico.md`](lexico.md) con vocabulario contemporáneo: tecnología,
inteligencia artificial, ciencia, mente, sociedad y verbos de uso frecuente. Las raíces
siguen siendo latinas/internacionales, transparentes a la vez para hablantes romances e
ingleses.

> Convención: `palabra` — español / *English*. Todo invariable; plural `-s` / `-es`.

## Frase de ejemplo (a tono con este repositorio)

> *Un modello de intelligentia artificiale apprende de multo datos. Primo nos
> exercita le rete neurale con exemplos; pois illa pote predice le resultato de
> novo datos. Si le predictione es bono, le systema es utile; si non, nos muta le
> algorithmo et exercita de novo.*

**Español:** Un modelo de inteligencia artificial aprende de muchos datos. Primero
entrenamos la red neuronal con ejemplos; luego puede predecir el resultado de nuevos
datos. Si la predicción es buena, el sistema es útil; si no, cambiamos el algoritmo y
entrenamos de nuevo.
