# Gramatica completa de Latino Simplo

Referencia detallada. Para la introducción y la filosofía, ver el
[`README.md`](README.md); para vocabulario, el [`lexico.md`](lexico.md).

---

## 1. Principio general

Latino Simplo es una lengua **aislante**: las palabras no cambian de forma.
Toda la información gramatical se expresa con **orden de palabras** (SVO) y
**partículas** invariables. No hay que memorizar ninguna tabla de terminaciones.

---

## 2. El sustantivo

- **Forma única**, tomada del tema latino (a menudo el ablativo): `homine`, `tempore`,
  `nomine`, `corpore`, `nocte`.
- **Plural** con `-s` tras vocal, `-es` tras consonante:

  ```
  casa → casas        flore → flores
  anno → annos        rege → reges
  ```

- Si el contexto ya marca cantidad (número, `multo`, `omne`), el plural es opcional:
  `tres anno` = `tres annos`.

---

## 3. El artículo (opcional)

|  | Singular | Plural |
|---|---|---|
| Definido | `le` | `les` |
| Indefinido | `un` | `unos` |

```
le homine ia veni.      El hombre vino.
un homine ia veni.      Un hombre vino.
homine ia veni.         (válido, sin artículo) Vino un hombre / vino el hombre.
```

---

## 4. El adjetivo

- **Invariable**, sin concordancia de número ni género.
- Posición normal: **tras** el sustantivo (uso romance), aunque se admite delante:
  `casa magna` ≈ `magno casa`.

### Grados de comparación

| Grado | Estructura | Ejemplo |
|---|---|---|
| Comparativo de superioridad | `plus … que` | `plus alto que tu` (más alto que tú) |
| Comparativo de inferioridad | `minus … que` | `minus caro que illo` |
| Comparativo de igualdad | `tanto … quanto` | `tanto forte quanto un leone` |
| Superlativo relativo | `le plus …` | `le plus bono de omne` |
| Superlativo absoluto | `maxime …` | `maxime rapido` (rapidísimo) |

Irregulares útiles (opcionales, “sabor latino”): `bono → melio` (mejor),
`malo → pejo` (peor), `magno → majo` (mayor), `parvo → mino` (menor).

---

## 5. Los pronombres

| | Sujeto / objeto | Posesivo |
|---|---|---|
| 1.ª sg | `io` | `meo` |
| 2.ª sg | `tu` | `tuo` |
| 3.ª sg m / f | `illo` / `illa` | `suo` |
| 1.ª pl | `nos` | `nostro` |
| 2.ª pl | `vos` | `vostro` |
| 3.ª pl m / f | `illos` / `illas` | `suo` |

- El **mismo** pronombre vale como sujeto y como objeto:
  `io vide illo` / `illo vide me`.
- Reflexivo: `se`. `illo lava se` (él se lava).
- Tras preposición, igual: `con me`, `pro te`, `de illos`.

---

## 6. El verbo

Cada verbo tiene **una raíz invariable** (infinitivo latino menos `-re`):
`amare → ama`, `videre → vide`, `dicere → dice`, `ire → i`.

### 6.1 Tiempos básicos — partículas antepuestas

| Tiempo | Partícula | Ejemplo | Traducción |
|---|---|---|---|
| Presente | — | `io ama` | amo / *I love* |
| Pasado | `ia` | `io ia ama` | amé / *I loved* |
| Futuro | `va` | `io va ama` | amaré / *I will love* |
| Condicional | `ave` | `io ave ama` | amaría / *I would love* |

> Las partículas vienen del latín y reproducen la lógica de las lenguas romances:
> `ia` < *iam* (“ya”), `va` < *vadere* (cf. esp. “va a”, fr. “vais”),
> `ave` < *habere* (las desinencias romances del condicional, esp. *amar-ía*, salen de ahí).

La partícula es **idéntica para todas las personas**:

```
io va ama · tu va ama · illo va ama · nos va ama · vos va ama · illos va ama
```

### 6.2 Aspecto — verbos auxiliares

| Aspecto | Estructura | Ejemplo | Traducción |
|---|---|---|---|
| Perfecto | `habe` + raíz | `io habe ama` | he amado / *I have loved* |
| Pluscuamperfecto | `ia habe` + raíz | `io ia habe ama` | había amado |
| Continuo (progresivo) | `es` + raíz`-nte` | `io es amante` | estoy amando |
| Continuo pasado | `ia es` + `-nte` | `io ia es amante` | estaba amando |

### 6.3 Modo

- **Imperativo**: raíz desnuda. `Ama!`, `Veni!`, `Audi!`, `I!`.
  Negativo: `non ama!` o `non vole ama` (no quieras amar).
- **Infinitivo**: forma plena en `-re`, tras verbo modal o como sustantivo verbal:
  `io vole amare`, `amare es bono`.
- **Verbos modales** (invariables): `pote` (poder), `debe` (deber), `vole` (querer),
  `sole` (soler). Se combinan con infinitivo:
  `io pote ire`, `tu debe studiare`, `illos vole manducare`.

### 6.4 Voz pasiva

`es` + participio en `-to`:

```
le libro es scripto.        El libro está escrito.
le casa ia es vendito.      La casa fue vendida.
le pane va es manducato.    El pan será comido.
```

El agente se introduce con `de` o `per`: `le poema es scripto de un puera`.

### 6.5 Participios y derivados

| Forma | Sufijo | Ejemplo | Uso |
|---|---|---|---|
| Participio activo / gerundio | `-nte` | `amante`, `currente` | adjetivo o continuo |
| Participio pasivo | `-to` | `amato`, `dicto`, `scripto` | pasiva, adjetivo |
| Nombre de acción | `-tione` | `creatione`, `narratione` | sustantivo abstracto |
| Agente | `-tore` / `-trice` | `creatore`, `narratore` | el que hace |

---

## 7. Negación

`non` siempre **antes** del verbo (o de la palabra negada):

```
io non sci.                 No sé.
illo non va veni.           Él no vendrá.
nihil es impossibile.       Nada es imposible.
```

Negativos léxicos: `nihil` (nada), `nemo` (nadie), `nunquam` (nunca), `nec … nec` (ni … ni).
No hay doble negación obligatoria: `io vide nihil` = no veo nada.

---

## 8. La interrogación

Tres recursos, combinables:

1. **Entonación** + signo: `Tu veni? ` (¿Vienes?).
2. **Palabra interrogativa** al inicio: `Ubi es le casa?`, `Que tu vole?`, `Quare tu ride?`.
3. Partícula opcional `an` para preguntas de sí/no enfáticas: `An tu es certo?`.

Respuestas: `si` (sí), `non` (no), `forsan` (quizás).

---

## 9. Orden de palabras

- **Neutro**: Sujeto – (partícula) – Verbo – Objeto.
  `Le puera ia da un flore a suo matre.`
- **Adjetivo** tras el nombre; **adverbio** junto al verbo: `illo curre rapido`.
- **Complementos** con preposición, en cualquier orden tras el verbo:
  `io va a le mercato con meo amico cras`.
- Para **enfatizar**, se puede anteponer un elemento: `Cras io va!` (¡Mañana voy yo!).

---

## 10. Formación de palabras (afijos)

Latino Simplo crece con prefijos y sufijos latinos transparentes:

| Afijo | Sentido | Ejemplo |
|---|---|---|
| `non-` / `in-` | negación | `non-possibile`, `injusto` |
| `re-` | repetición | `re-face` (rehacer) |
| `pre-` | antes | `pre-vide` (prever) |
| `con-` | con, junto | `con-labora` (colaborar) |
| `-tione` | acción/resultado | `constructione` |
| `-tore` | agente | `inventore` |
| `-bile` | posibilidad | `legibile`, `amabile` |
| `-oso` | abundancia | `famoso`, `periculoso` |
| `-mente` | adverbio de modo | `rapidamente`, `claramente` |
| `-eto` / `-ulo` | diminutivo | `casuleta`, `libreto` |

> El sufijo `-mente` permite crear adverbios al gusto romance, pero también vale el
> adjetivo desnudo como adverbio: `illo parla claro` = `illo parla claramente`.

## 11. Resumen de partículas

| Partícula | Función |
|---|---|
| `ia` | pasado |
| `va` | futuro |
| `ave` | condicional |
| `habe` | perfecto (auxiliar) |
| `es` | cópula / pasiva / continuo |
| `non` | negación |
| `an` | interrogación sí/no |
| `le` / `un` | artículos |
| `plus` / `minus` / `maxime` | comparación |
