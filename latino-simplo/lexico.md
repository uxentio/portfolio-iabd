# Lexico — Diccionario de Latino Simplo

Vocabulario temático. Cada entrada deriva de una raíz latina elegida para ser
**transparente** a la vez en lenguas romances y en inglés (vía vocabulario culto).
Todas las palabras son **invariables**; el plural se forma con `-s` / `-es`.

> Convención: `palabra` — español / *English*

---

## Pronombres y demostrativos

| Latino Simplo | Español / *English* | Latino Simplo | Español / *English* |
|---|---|---|---|
| `io` | yo / *I* | `nos` | nosotros / *we* |
| `tu` | tú / *you* | `vos` | vosotros / *you (pl.)* |
| `illo` | él / *he* | `illos` | ellos / *they (m.)* |
| `illa` | ella / *she* | `illas` | ellas / *they (f.)* |
| `se` | se (reflexivo) / *-self* | `on` | uno, se (impersonal) / *one* |
| `hoc` | esto / *this* | `illoc` | eso, aquello / *that* |
| `omne` | todo / *all, every* | `alio` | otro / *other* |
| `mesmo` | mismo / *same/self* | `tale` | tal / *such* |

**Posesivos:** `meo, tuo, suo, nostro, vostro` (invariables).
